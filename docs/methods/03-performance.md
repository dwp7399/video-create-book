# 03 人物、行动与表演

人物不是形容词列表。可拍摄的表演需要目标、对象、动作和反应发生的时间。前置为[结构与信息](02-structure.md)；空间落实接[场景设计](05-staging.md)。本章分镜为自创教学示例，章末附有按分镜生成的 AI 参考成片；成片只是一种实现，效果仍要在自己的观看条件下检验。采访内容只能从实际受访者取得。

## 03-01 把情绪指令改为行动任务

**定义与机制。** 行动任务写“向谁争取什么、用什么办法”，例如“让陈晚一点拿走伞”，而不是只要求“纠结一点”。可见策略与对方反应形成往返 → 观众据此推断关系和心理。情绪可以是结果，不能当作唯一执行指令。

**适用与准备。** 适用于演员、动画角色与需要动作表达的 AI 镜头；纯物体视频可转成对象状态变化。准备本场进入/退出状态、人物知道什么、空间和道具。人物小传只保留会改变本场选择的经历、关系和习惯，不写与行为无关的大量设定。

**步骤。**

1. 写每人的即时目标和阻力；同一场不要求每个角色都拥有宏大人生目标。
2. 将场景切成“新信息使策略变化”的节拍，每拍用动词命名：确认、拖延、试探、解释。
3. 给演员任务和对象，让其先在无台词条件下完成；观察动作是否自然、是否过多。
4. 保留能让对方作出反应的停顿，删掉重复传达同一信息的动作。
5. 用全景排练确认事件完整，再决定需要哪些近景；不要先把表演切碎后才寻找关系。

**组合。** 与潜台词、调度相连；目标先确定，距离、遮挡和道具再提供策略。动画需要把意图转为可辨姿态；摄影应给重要反应留可观察空间。

### 公共场景：不增加台词，改变行动的指向

沿用 A：林想把最后一把黄色长柄伞留给店外成年周；成年陈不知道。柜台左、伞架中、门右；林在柜台后，陈在前；周在右侧玻璃门外。林右手触伞柄；伞不离架。全部镜头在同一轴线店内侧，无字幕，无旁白、无音乐；0–12秒持续雨声与室内底声，台词只在第1镜出现。基线和变化都12秒，镜头顺序、时长、机位及文字不变，仅改林与陈的动作节拍。

| 镜号 | 时间/时长 | 画面与信息 | 景别/机位 | 人物动作 | 相机运动 | 声音 | 文字 | 剪辑/连续性 |
|---|---|---|---|---|---|---|---|---|
| C03-A01 | 0–3 / 3秒 | 陈要买伞，林接收请求 | 双人中景，柜台前同侧 | 陈指伞并说话；林全程皱眉 | 固定 | 陈“这把伞，我要了”；雨/底声；无音乐 | 无 | 话尾切；伞在架 |
| C03-A02 | 3–6 / 3秒 | 林迟疑，但动作对象不明 | 林中近景，同侧，门外周为背景 | 林皱眉、叹气、看地面，右手停在身前 | 固定 | 叹气、雨/底声；无对白/音乐 | 无 | 叹气结束切；尚未触伞 |

| C03-A04 | 9–12 / 3秒 | 林仍未解释 | 林中近景，同侧 | 林右手触柄，继续皱眉 | 固定 | 接触声、雨/底声；无对白/音乐 | 无 | 触柄后停；伞仍在架 |
| C03-A11 | 0–3 / 3秒 | 同一请求使林准备行动 | 双人中景，与 A01 同 | 陈同样指伞说话；林看向伞准备伸手 | 固定 | 同句对白、雨/底声；无音乐 | 无 | 手尚未触柄，准备动作接下镜 |

| C03-A13 | 6–9 / 3秒 | 陈尝试确认能否拿伞 | 陈近景，与 A03 同 | 陈看林的手，再看林；伸出空右掌半途停住 | 固定 | 雨/底声；无对白/音乐 | 无 | 手停在身前，等待回应 |

变化版将笼统负面情绪改成有对象的准备、察觉、中止和回应，预计更容易读出冲突来自伞的去向。镜头参数保持一致，但动作与相关动作声随执行变化；表演不保证每位观众都推断出完整背景。

**错误与返修。** 所有节拍同一表情 → 没有策略转变 → 给新信息后的新动作；每句话配一个大动作 → 抢信息 → 删除不改变关系的手势；林知道周、陈也突然跟着看周 → 知情边界失守 → 保留陈只看林与伞。

**检查。** 无对白排练能否看出请求和迟疑？角色在回应对方还是展示情绪？手与伞状态能否跨镜衔接？12秒是否容纳动作和理解？检查紧张感时先问人物在做什么，再问感受。

**媒介适配。** 实拍先完整走戏再拍覆盖，选条兼顾对方反应；动画先画“伸手—察觉—停住—转向”姿态，不靠眉毛完成全部表演；AI 拆为短动作目标，难以稳定握柄时改为手近柄处停住，并全片统一状态，不混用握住/未握素材。

## 03-02 让潜台词来自说话目的与听者反应

**定义与机制。** 对白是人物可听到的语言；潜台词是语句在关系中执行的目的与未直说的内容。“您现在就走吗？”可询问时间，也可拖延交易；意义来自处境、重音、停顿、视线与听者回应，而非台词本身藏着固定密码。

**适用与准备。** 适合人物不愿或不能直说的场景；关键信息本就稀缺时不宜让每句都含蓄。先写一句直接意图，再改成角色在此关系中愿意说的表达，并确认观众已有必要背景。

**步骤。** 标记一句话向谁争取什么；写出听者可能的理解；排练直说与含蓄两版；调整重音、说话起点和停顿而非只要求“更有深意”；检查对白是否抢先说完画面已经表达的信息。

**精确示例。** 共用 C03-A11→A14，镜头与总长仍12秒。直说版：A14 的9.3–11.4秒林说“我想把伞留给门外的人”，让陈立刻取得新信息。潜台词版：同一时段林说“您现在就走吗？”，9–9.3秒松柄，9.3秒看陈才开口，11.4–12秒等答复；其余不变。两版均保留雨/底声、无音乐与文字。直接版用于推进明确协商；含蓄版保留陈不知缘由的状态、使林尝试拖延。二者不能接同一个假定陈已知的后续剧本。

**组合。** 先决定知情权限，再选含蓄程度；与反应镜头组合时给听者处理新信息的时间。用字幕呈现对白时，不加解释内心的旁注破坏潜台词。

**错误与返修。** 句句话外有话 → 目标难理解 → 让至少一条请求明确；把旁白当角色内心万能说明 → 削弱行动 → 删旁白做一次无旁白预演；用夸张语调提示“这里有秘密” → 过早暴露 → 回到真实对话任务。

**检查。** 字面与意图是否不同且有依据？陈此刻听懂了什么？语速是否清楚而非靠快说挤时长？台词录音或动画口型是否可完成？观众不理解时先补处境，不先加更多隐喻。

**媒介适配。** 实拍用不同任务试台词，避免按字模仿导演语调；动画先录临时声音再定口型与反应时长；AI 可用画外对白配反应镜头，若展示正面说话仍须核对音画同步，不能用字幕掩盖明显不一致。

## 03-03 用反应、关系与排练选择表演节拍

**定义与机制。** 反应不是对白之间的填空，而是人物从接收信息到调整策略的可见过程。关系可通过谁先行动、谁等待、距离、视线和物件控制呈现。排练用于发现可重复的动作结构，选条则按场景目标、可信度与剪接条件取舍，而非只选表情最大的一条。

**适用与准备。** 适用于含对话、交易、合作或对抗的场景。准备场景全景、动作节拍及连续表；给演员解释关系和任务，不要求私人经历作为唯一素材。

**步骤。** 无相机走一次完整行动；分别试主动确认、耐心等待、误以为拒绝三个任务；记录何时出现真实反应；再加机位检查遮挡；每条拍完记录行为变化、时间与技术问题；用相邻镜头组合选条，检查一个反应是否确实回应了前一信息。

**精确示例。** C03-A13 的6–9秒，版本一陈在6秒立即皱眉伸手；版本二6–7秒看林停住的手，7–8秒抬眼看林，8–9秒伸掌后停。其余镜头与声音不变。第二版预计使反应显得由林的迟疑触发；第一版可能更急迫，若陈本来赶时间也可成立，但需要上文支持。此例不规定“慢反应一定自然”。

**组合。** 和时间章的持续、停顿联用；摄影覆盖应保留反应发生前后的素材余量。剪辑可以提前切到听者，但不能把未听见的话剪成该人物已知的信息。

**错误与返修。** 近景很精彩但手态接不上 → 只评表情 → 查连续表并补手部接点；演员每遍重演同一个表情 → 指令过于结果化 → 改任务；反应太早 → 演员预知台词 → 调整接收与行动节拍。

**检查。** 反应对应哪个刺激？关系是否通过动作而非说明呈现？相邻镜头中的手、视线、道具状态一致吗？必要停顿是否有足够素材？情绪判断使用多位观看者反馈，不能把导演自评当验证。

**媒介适配。** 实拍记录每条的起止动作、选条理由与拾音；动画通过姿态保持和过渡呈现信息处理；AI 多个候选按同一节拍表筛选，不把偶然面部漂移解释成复杂心理。

## 03-04 引导非演员与采访，但不替他们制造事实

**定义与机制。** 非演员引导为真实参与者提供清楚任务和沟通方式；采访通过具体问题取得其经验与判断。它们不等于导演预先写好真实人物应说的话。观察、引导、重演和虚构须分清，才能保留可信度。

**适用与准备。** 用于纪录、Vlog、人物介绍与真实使用演示。先说明用途、参与方式和素材使用范围；准备开放问题、空间、收音、停顿时间及不打断的观察段。母题 C 的人物、动作、台词与结果必须现场取得。

**步骤。** 先请对方描述一个具体过程；用“当时发生了什么、你接下来怎么做”追问，避免把答案塞进问题；让操作者按实际流程做；不懂处再请其解释，而不是要求伪装第一次发生；记录哪些镜头属自然观察、按请求演示或事后重演；剪辑保留影响理解的限定条件。

**现场拍摄提纲，不是虚构分镜。** C03-C01 记录衣物实际检查，机位以看清手与衣物为先、固定中近景、不中断动作；C03-C02 在自然停顿采访“你刚才检查的是什么？”，固定中景、人物按自己的话回答；C03-C03 补拍其提到的实际部位，固定近景，若为另一次演示则登记。三个镜头的时长、对白和结果记“现场待取得”，环境与操作声连续采集，无预置音乐。该提纲不能算已经拍到的证据或已闭合的成片时间表。

**组合、错误与返修。** 与01章证据表结合；回答笼统则追问具体一次经历；采访者频繁打断导致无法剪接则让其完整再说一次并登记重述；将不同时间的皱眉接成对某问题的不满则回到真实对应素材或取消该推断。

**检查。** 引语是否保留原意？人物是否被要求扮演预设性格？声音是否清楚、停顿是否充分？自然过程不可重来时是否优先保证关键覆盖？无真实素材前不填写人物答案。

**媒介适配。** 实拍保存问题与完整回答；动画转述须保留来源、注明重建或示意；AI 合成的人物表演不作为真实采访或真实当事人的证词。缺素材时收窄结论，而非生成伪证。

## 本章实践交付

用四个可演动词代替四个情绪形容词；给每次反应标刺激；按同一镜头设计试两个行动任务；记录选条理由和动作接点。若做纪录片，另交观察/引导/重演记录及采访原意核对表。
