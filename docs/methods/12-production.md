# 12 制作与协作：让创作决定变成可交接的素材

本章接续[场景设计](05-staging.md)、[声音设计](09-sound.md)及[条目规范](../guide/03-technique-template.md)。制作包不是文件数量竞赛：它要让接手者知道每镜为什么需要、如何取得、什么状态算可用，以及失败后如何继续。以下工作表为教学示例，金额与工时需按实际项目填写。

## P12-01 从表达目标拆出制作包与预算

**解决问题与定义。** 脚本写了“紧张地递出物件”，现场却不知道必须拍到什么，预算也只列设备费。制作拆解把创作要求转换成资产、人员、时间、依赖及验收；它不同于拍摄顺序，也不等于把脚本逐句复制进表格。

**机制与适用。** 将必要信息绑定到明确镜头和资源，可以提前发现“没有反应镜头”“支架与设备不匹配”等缺口。适用于所有制作路径；探索性纪录无法预设真实结果，应拆解观察条件和备选覆盖，而非要求现实按剧本发生。

**准备。** 一页简报、批准的事实范围、结构与分镜、声音任务、交付用途。先区分必需项与可删项：失去它是否会使主张、因果或观看条件不成立？

**操作。**

1. 按场景/段落列出演员或对象、场地、道具、声音、文字、授权素材及后期需求，每项指回镜号。
2. 为每镜写“必须可见/可听的信息”和可用标准；另标关键动作接点，不以“漂亮”验收。
3. 把任务串成依赖：道具确定后才能锁特写；录音场地预查后再定对白覆盖；动画动态分镜通过后才细化。
4. 分开估算准备、执行、切换、选片、返修及交付成本。现金预算与工时预算并列；工具费用之外还要计人工检查。
5. 给高风险环节设置试验额度和停止条件。额度由项目承担能力确定，不把固定返修比例当普遍规律。
6. 用一次桌面走查验证：任意指定一镜，执行者能否找到素材、负责人、入出状态和验收人？缺少这些就补包，不急于开拍。

**案例 B：小型桌面演示制作拆解。** 本片只表达支架在本次桌面与设备条件下能够支撑、折叠和收纳。以下是计划，不是产品性能证据。

| 工作包 | 输入与关键任务 | 输出及验收 | 依赖/责任 |
|---|---|---|---|
| B-P1 事实及样品 | 同一无品牌支架、同一设备、桌面；记录本次可观察行为 | 状态照片与主张表；不出现未测耐重/寿命 | 制片/内容负责人 |
| B-P2 预演 | 用样品试开合、摆放和取下设备；手机草拍即可 | 动作顺序可执行；无隐藏支撑；操作者知道停留位置 | P1；导演/操作者 |
| B-P3 画面 | 固定全景说明条件；侧面记录支撑；特写展示关节；收纳结果 | 每镜有动作前后余量；关键连接位置看得见 | P2；摄影 |
| B-P4 声音 | 安静环境、放置声、折叠声、环境底声；需要旁白时另录 | 原始声音可辨识、无削波；每条对应镜号 | P2；录音 |
| B-P5 后期 | 同步、选条、粗剪、字幕、调色、声音层级 | 不剪掉影响主张的条件；文字不挡支撑点 | P3/P4；剪辑 |
| B-P6 验收交付 | 首次观看、产品状态检查、导出回看 | 能说明演示范围；文件可播放；包内可追溯 | P5；负责人 |

示范工时预算可写“准备2小时、预演1小时、画面与声音3小时、后期4小时、检查1小时、风险额度2小时”，合计13小时；这是练习的资源假设，不是报价或保证。若执行时间只有8小时，先删重复角度和包装，而不是删支撑证据与声音检查。实际记录与估算相差时，写原因，供下一次调整。

**基础与变化。** 基础版只列“拍摄半天、剪辑一天”；变化版为上表。保持片长与表达不变，增加依赖和验收信息，预计减少等待与补拍，但不能未经生产验证声称节省了多少成本。

**组合。** 与[AI 工作流](../ai/A1-content-design.md)结合时，把生成候选和筛选算独立工作包；与动画结合时，以动态分镜批准为细化前置，避免镜头删改带来整段重做。

**错误→返修。** 设备齐全但缺镜头：按观众必须知道的信息倒查覆盖；预算反复失控：补上切换与返修工时；对每个镜头都列十种风险：只优先预试会阻断叙事或证据的项目。

**检查与媒介差异。** 能否追溯每个资源服务什么表达？删掉可选项后情绪节拍是否仍成立？状态及声画要求是否能交接？实拍重场地与人时；动画重资产复用和细化顺序；AI 重候选成本和替代路线。纸面通过不等于素材已经可用。

## P12-02 用排练、预演与现场覆盖保证可剪素材

**定义与机制。** 排练验证人物/对象如何行动，预演验证观众看见什么，覆盖验证后期有足够材料连接。三者共同把“动作能发生”与“动作能被理解”分开测试。适合有表演、操作或运动的段落；纪录观察可以预查机位和声音，不能为补连续性要求当事人伪装成首次行为。

**步骤。**

1. 从场景进入/退出状态出发，把动作拆成准备、执行、结果、反应。先排动作，不要求演员模仿抽象情绪标签。
2. 用草图或低成本试拍测试空间、视线与画外声；实际观看一次，检查关键动作是否被遮挡、是否给足辨认时间。
3. 列最少覆盖：建立空间、关键动作、结果/反应；不是每场都必须全套景别，而是每个必要信息都有载体。
4. 开拍前确认镜号、条号、收音状态和道具复位；拍后当场确认画面、声音、焦点和关键动作，不只看缩略图。
5. 每条记录可用入点、出点、最佳表演、问题和接续状态。留多少余量由动作及剪辑需要决定，不机械规定每镜多录固定秒数。
6. 场地状态稳定时录独立环境底声和关键动作声；重要对白戴耳机监听。无法用后期恢复的漏录及时补采。
7. 每个场景收工前做一次简易串接或按镜号走查，确认能够从进入状态接到退出状态。

**案例 A：排练与覆盖卡。** 公共事实：店员林想把最后一把黄色长柄伞留给店外周；成年顾客陈不知情。本练习只覆盖林迟疑，并未改变伞的归属。以下镜头清单采用独立制作练习编号P12-A01—03；这是覆盖素材，不是已排定时长的成片。

| 节拍 | 演员/对象任务 | 画面覆盖与声音 | 连续性及通过条件 |
|---|---|---|---|
| P12-A01 陈指向伞 | 陈右手指架上伞，收回手；林看陈再看伞 | 柜台双人中景；雨声隔门较远；不要求对白解释全部 | 伞仍在架；视线对象明确 |
| P12-A02 林停住 | 林右手伸向伞柄前停住，保持未接触 | 手部近景与林反应各一条；服装动作声自然 | “想取却停住”可读，不凭微小表情猜测 |
| P12-A03 林望门外 | 林目光转向门外周，再回到陈 | 眼线一致的反应；门外画面作可选覆盖 | 周位置不变；雨声连续，不偷换时段 |

基础版只拍完整双人中景；变化版增加“手停住”和“望门外”覆盖。保留行为与事实；预计剪辑可更明确控制迟疑的原因何时被看见。若原中景已清楚且持续表演更有力量，可不使用新增镜头，覆盖不等于成片必须全用。

**组合。** 与调度共同决定相机位置，与声音章共同确定监听与声源，与剪辑章共同确认接点；先决定看点，再增机位。

**错误→返修。** 每条表演好但接不上：复位持物手、视线和动作阶段；对白清楚但底声骤变：补对应环境底声并检查声场；反复拍同一问题：暂停回看排练，改机位或动作，不仅增加条数。

**检查及适配。** 观众能辨认行动目标吗？停顿是否仍有期待而非等待指令？接点的手、视线、物态是否一致？实拍记录实际选条；动画先用简化姿态与临时声音预演；AI 先验证起止状态与接续，再批量生成。纪录 C 中漏掉的一次真实动作应承认素材不足，可用采访澄清或标示重演，不能暗中补演冒充原始观察。

## P12-03 用镜头台账与版本记录完成交接

**定义与机制。** 素材台账记录来源与可用区间，版本记录说明成片使用了什么和为何改动。它们让协作者从最新事实继续，而非凭文件名猜“最终版”。小作品也适用，但不需引入超出团队能力的复杂管理软件。

**准备与步骤。**

1. 定义稳定镜号、资产 ID 和版本编号。目录示例：`01_brief/`、`02_assets/`、`03_source/`、`04_project/`、`05_exports/`、`06_review/`；原始素材保留不覆盖。
2. 入库后核对文件可读、音轨存在、时长及帧率记录。根据项目价值建立独立备份；“复制完成”之后还需抽查或校验，不能把同一盘的另一文件夹当独立备份。
3. 同步依据优先使用可靠时间码或场记声画标记，再人工检查口型/接触瞬间。剪辑代理与原始素材保持可回连关系。
4. 用唯一版本号导出审片，如 `B_cut_v003_review`；注明项目时间基、尺寸、字幕状态、临时音乐和待处理项，不在文件名写一串“final”。
5. 每次修改记录问题 ID、时间码、改动和影响范围。定格图片可辅助定位，但不能替代有时间信息的问题单。
6. 交接包包含工程、可回连素材、字体/图形依赖说明、声音分轨、参考导出、版本记录及下一步；外来素材保留来源和允许用途记录。
7. 接收者在另一位置打开工程并回连，检查选定镜头和音轨。成功才标交接完成；仅发压缩包不算验证。

**案例 B：可直接复制的台账行。** 此处B03是独立的台账填写演示，不对应综合案例B1-03的成片时段；转入具体项目时，应改成该项目唯一镜号与实际入出点。

| 项目 | 示例记录 |
|---|---|
| 镜头/源文件 | B03 / `B03_take02_original`；文件名示意 |
| 内容/状态 | 同一支架打开，设备已放稳；关键支撑接触点完整可见 |
| 可用范围 | 源文件00:02–00:06；动作前后稳定，实拍后填准确时间 |
| 音频 | 放置声独立轨 `B_FX_place_01`；拟音使用需记录，不把补声当实测证据 |
| 成片使用 | `B_cut_v003` 的00:06–00:10；待实际剪辑确认 |
| 问题/处理 | 光色稍偏；先与邻镜匹配再判断是否补拍；不裁掉桌面接触点 |
| 下一步 | 剪辑检查支撑条件完整 → 负责人验收 → 导出版本 |

基础交接仅给一个压缩视频；变化交接给工程、来源与下一步。保持成片不变，变化在可追溯性；他人可以修改而不必重问全部背景。

**错误→返修。** 离线素材：对照台账恢复路径并重新回连；错误版本被审：在审片记录锁定文件与版本；代理回连后声音不同步：核查时间基和音频重采样设置，定位偏移来源；动画渲染或 AI 候选混用：检查资产版本血缘，不只看外观相似。

**检查与适配。** 交接人能复述本版目标与未解决问题吗？临时音乐替换是否影响节奏？镜号、物态和时间基可追踪吗？实拍保存场记与原始声画；动画保存布局、资产、动画、合成版本关系；AI 保存输入参考、提示词、工具版本/日期、候选与采用区间。若某种身份训练不能导出文件，台账记平台内名称、训练日期和已批准静帧，不能只写“已训练”。这类限额见[操作备忘](../ai/higgsfield.md)。工具设置的准确支持情况在执行时核对，不靠本书保证兼容。

## 本章实践交付

提交制作拆解、估算与实际工时、预演反馈、覆盖和录音清单、素材台账、一次可验证交接。若尚未生产，所有可用区间与验收结果保持“待填”，不得将计划值包装成完成记录。[下篇A1](../ai/A1-content-design.md)把这些原则用于AI生成。
