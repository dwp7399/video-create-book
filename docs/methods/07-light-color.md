# 07 光线、色彩与材质

光线先解决“什么能看见、什么有体积、来自哪个空间”，色彩再参与注意与全片关系。前置：[世界与风格](04-world-style.md)、[镜头](06-camera.md)。本章分镜为自创教学示例，章末附有按分镜生成的 AI 参考成片；成片只是一种实现，效果仍要在自己的观看条件下检验。不提供脱离场景的通用曝光、白平衡或平台色彩数值。

## 公共练习：让最后一把伞成为可辨线索

A 母题事实保持不变，空间采用[05章](05-staging.md)：相机在柜台西侧，门在画面右方，黄色长柄伞竖在柜台东端架内。店内顶灯是室内光的叙事动机，门外有街道来光。动机说明观众为何相信光在那里，不要求全部照明只用画内可见灯具。

两版都是 9 秒，同相机、动作、声音、剪辑与服装。基础版假定店内照明均匀、门外招牌较亮；变化版只改变光的分配和背景亮度：门外仍可读但不压过手部，伞柄和手有明暗分离。不是“暗就是高级”，而是围绕取伞这个观看任务调整注意。全场无字幕音乐；雨声 0–9 秒，陈对白“就这把”1–2 秒，林“等一下”5–6 秒。

## LC01 从实际光源出发建立明暗层级

**定义、机制与边界。** 光线动机是光与场景世界的关系；明暗层级是观众辨认重点的线索。照度、方向、光源相对大小、反射与遮挡共同影响脸、物体和空间，不用“柔和”一词包办所有选择。动机可信不等于自然拍摄必然清楚，也不等于人物只能被头顶灯照到。

**适用与限制。** 适用于剧情、美术化动画和需要看清形体的演示。观察式纪录若现场不宜改变光线，先调整拍摄位置或等待合理时机，不能重演真实事件冒充观察。准备场景光源图、重要区域优先级、皮肤和伞的材质参考。

**步骤。** ①关掉或遮挡可控的竞争来源，分别观察各光源作用。②先让关键动作可见，再建立背景层次。③从每个计划机位检查反光和阴影，不能只看全景。④按最终显示环境预览，判断人物、动作、地点是否仍可辨。

**示例与组合。** L-B01→L-V01 先控制门外招牌竞争，再让手与伞有分离；L-V02 保持大方向，而非把每个特写单独打成最漂亮的正面光。结合[场景调度](05-staging.md)：如果手伸入暗区，先判断是否可改站位，再增灯，避免光反过来破坏动作目标。

**错误→返修。** 脸好看但手势不见→只照人物没照事件→补动作区域或调整路径；特写阴影朝向相反→各镜单独布光→以空间主光方向重新匹配；背景全黑导致门不知在哪→层级过度→保留必要地理锚点。

**检查。** 理解：能看见谁阻止谁吗？情绪：暗部让人克制还是单纯看不清？连续：光来自同一空间吗？执行：走位全程可保持，还是演员一动就失效？实拍记录灯与遮挡位置；动画锁定灯光布局再局部调整；AI 使用同一光向参考并检查跨镜，提示词中写“光线一致”不足以验收。

## LC02 给颜色分配职责，再画色彩脚本

**定义与机制。** 配色决定同一时刻的颜色关系；色彩脚本描述这些关系如何随段落改变。颜色能通过对比、重复和变化建立关注或联系，但没有脱离文化与语境的固定情绪字典。“蓝色必然悲伤、红色必然危险”不是可用的创作推理。

**适用与限制。** 用于道具辨识、空间区别、动机重复和段落转折。产品说明必须维持产品可识别的真实外观；身份或线索依赖黄色伞时不能为了统一风格把它调成另一颜色。准备关键色样、相邻场景参考和观众需要记住的对象。

**步骤。** ①选一个主导关系，如低饱和环境中黄色伞是识别点。②明确哪些颜色是事实锚点，哪些可由美术控制。③按段落画三个小色块图：进入、变化、退出，写明变化由灯、空间还是主观表现引起。④把图放到一起再检查单镜，不追求每张都独立抢眼。

**示例与精确变体。** 保持 L-V01–03 的 0–9 秒全部动作、声轨与光线方向；LC02-A 保留鲜艳背景包装，LC02-B 将可控背景包装换成低竞争配色，伞色不变。这是美术配色变量，预计降低寻找伞的负担。色彩脚本在本片段内可完全不变：0–3 建立黄色伞，3–6 继续保其身份，6–9 仍在画外关联林的行为。并非每场必须“由冷到暖”。

**组合。** 先由[美术与风格](04-world-style.md)决定颜色职责，再由曝光和调色确保可复现；文字强调色需服从相同层级，不能抢过关键动作。

**错误→返修。** 每个物件都高饱和→无主次→减少竞争色；调色后伞跨镜变橙或绿→全局风格损伤身份→先校正物件与肤色再做整体处理；为情绪转折突然变色→缺乏动机→增加可见光源变化，或明确采用主观形式规则。

**检查与适配。** 观众能记住核心道具吗？颜色变化是否被误认成物件变化？相邻镜头的关键色是否匹配？实际材质和显示条件能否维持差别？实拍以色样和现场参考记录；动画共享材质资产；AI 锁定道具图并逐镜核色，必要时后期局部校正而非整镜重生成。

## LC03 先保可用素材，再做镜间匹配和风格调色

**定义与机制。** 曝光决定记录到的亮暗信息；白平衡处理成像中对光源颜色的解释；校正先解决各镜可用性与匹配，风格处理再组织整体感受。后期不保证恢复已丢失的关键高光、严重噪声或被遮住的细节。自动调整可能随构图变化造成同场跳动，需要根据设备和现场选择可重复的策略。

**适用与限制。** 一切需要跨镜一致的制作都适用；混合光环境未必可以靠单一白平衡让所有区域中性，目标应是有意且可接续。准备关键对象参考、拍摄/渲染设置记录、监看与输出测试环境。

**步骤。** ①先检查最亮的必要细节与最暗的必要动作，确定二者可用。②在选定位置记录参考物和肤色，不把参考卡置于完全不同的光里。③同场覆盖保持或记录设置变化。④后期先按主镜对齐曝光、颜色与关键物件，再做整体风格；最后用实际输出文件复查。

**精确例。** L-V01 为主镜。对 L-V02 3–6 秒先核伞柄仍有质感、黄色与主镜相容，再匹配手部相对亮度；L-V03 6–9 秒因近景背景比例改变，不要求全画面平均亮度机械相同，而要求脸、门侧方向及时间感连续。基础版 L-B02 若亮部真的记录丢失，变化版应重拍/重渲染，不能写成一个滤镜就恢复。

**材质补充。** 湿伞或光滑柜台的反射会随机位改变。先改变灯与物件/相机的夹角或控制反射面，再决定是否降低整体曝光；否则为压住一个反光让所有人脸变暗。需保留的高光是形体和材质线索，不是全部抹掉。

**错误→返修。** 切镜瞬间脸色跳动→设置或光源不一致→先匹配基准；用滤镜掩盖色偏→叠加偏差→退回校正层；只在剪辑预览正常、导出偏差大→显示/输出流程未验证→对照同一测试片的预览与实际输出，查工具当期官方说明，不盲改全片。

**检查与适配。** 信息细节是否可用，风格是否帮助情绪而非损害阅读，关键色/光向/材质是否跨镜连续，输出可否复现？实拍记设置与参考；动画统一渲染和色彩流程；AI 先筛闪烁、光向漂移和材质融化，局部明暗可后期修，几何与遮挡错误回到生成或合成。

## AI 光色执行卡

本卡是 L-V01–03 的补充要求，不声称任何模型一定支持。参考资产为自制空间图、同一黄色伞照片、林陈角色图、店内与门侧光向示意，登记来源和版本。

| 项 | 执行要求 |
|---|---|
| 输入/输出 | 分别做中景、手部近景、林近景；用同一室内主光方向、门侧来光和伞色参考；起止姿态沿本章时间表 |
| 提示词样例 | “便利店柜台西侧固定手部近景。陈右手接近架中黄色长柄伞，林左手伸入挡住，伞不移动。店内顶灯提供主照明，画面右方门侧轻微来光，保留伞柄质感；背景较暗但可辨，沿参考保持黄色和手部身份。” |
| 运动控制 | 主体仅按两手动作变化；相机固定；光源、背景与伞色不随动作闪变 |
| 一致性检查 | 逐帧看手、伞、光向、阴影及反射；跨镜对照主镜，不只选一帧好看的结果 |
| 候选记录 | 镜号/输入版本/可用区间/光色与几何问题/接受或淘汰；本书尚无实际候选 |
| 失败替代 | 色彩轻偏可校正；光源跳动严重则重做或用实拍/动画；两手不稳按05章拆成单手与反应 |
| 后期拼接 | 使用各 3 秒片段，先对齐伞色和手部明暗，再铺连续雨声与对白；不以调色隐藏动作或产品事实变化 |
