# 阅读路径与实践顺序

先读方法论、模板，再按目标选路。章号对应完整大纲和 chapters/ 文件；上篇01—13，下篇A1—A4在 chapters/ai/。每条路径均先完成一个小作品，再扩展时长和技术复杂度。

| 视频用途/形式 | 推荐阅读顺序 | 最小实践与验收 |
|---|---|---|
| 剧情短片 | 01→02→03→09基础→04→05→06→07→08→12→13 | 拍/预演同一场景两版，观众能复述人物目标与改变 |
| 纪录片 | 01研究→02观察/论证→03采访→09→05/06→12→08→13 | 记录一个完整过程并建事实台账；剪辑不制造不存在的因果 |
| 广告/产品演示 | 01→02承诺/证据→06/07→10→09→08→12→13 | 一个主张、一段可观察证据、一个清晰行动入口；事实与条件一致 |
| 教程/科普 | 01→02步骤/论证→05→06→09/10→08→13 | 陌生读者按步骤可复现；结论可回溯到证据 |
| 短视频 | 01观看条件→02→10→08/09→12→13，按内容补03或06 | 同内容两种开头承诺；首次观看复述与兑现检查，不假定快剪优越 |
| Vlog | 01→02观察/旅程→05/06→09→12→08→13 | 一次行动的起因、过程、变化；环境和个人旁白职责清楚 |
| MV/舞蹈 | 01→09音乐结构→08基础→04→05/06→11→08深化→13 | 一段音乐三次动机变奏；声画同步/对位选择有依据，不要求静音完整 |
| 动画 | 01→02/03→04→09基础→05→11→06/07→08→12→13 | 先姿态和动态分镜，再细化；动作重量、接触和阅读时间成立 |
| 实验影像 | 01→04→09→08→06/11→13 | 定义一个感知规则，建立、重复、偏离；检查观众能否感知变化而非强求情节 |
| AI 辅助或混合 | 先走内容类型路径→12→下篇A1→A2→A3→A4→13 | 先预试最危险镜头，再做序列；连续性、必要细节与可剪长度过关 |

## 所有路径共享的七次练习

1. **一页简报**：一句观众变化、一个限制、一个验收问题，避免只写“高级、震撼”。
2. **纸面结构**：每段写新增信息或感知变化，删除无法解释功能的段落。
3. **声画预演**：用草图、临时声音和时间表走一遍，不等精美资产就检查可读性。
4. **单变量对照**：同素材改顺序、停顿或声音之一，写出机制假设。
5. **小规模生产**：先一个场景，记录素材、动作接点与失败原因。
6. **粗剪与盲看**：先让观看者复述，再讨论感受；按目标选择静音/只听/合看。
7. **修改与交付**：问题回到原决策层，保留修改前后版本及原因。

## 从图片创作迁移

已有图像基础可快速读04/06/07，但不要跳过05空间、08时间剪辑、09声音、11运动。练习从“一张构图”扩展为“同空间三个状态”：进入、变化、离开；再加一个画外声源和两次切换。检查视觉重点能否随动作持续被发现，而不只是关键帧好看。

## 类型不是互斥盒子

一个项目可同时标记：用途=教育，组织方式=观察+说明，生产=动画+实拍，发行=竖屏短视频，风格=克制纪实。先选内容路径，再叠加生产和交付要求；不要因选择 AI 就跳过叙事、空间与声音。
