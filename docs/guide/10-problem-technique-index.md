# 从问题找到技法和案例

先定位观众实际遇到的困难，再选技法。下表列的是检查方向，不能仅凭“拖沓”“不高级”等印象判断原因。章节内用列出的技法ID检索；

## 内容、理解与人物

| 遇到的问题 | 先做的检查 | 可选技法与入口 | 练习或返修方向 |
|---|---|---|---|
| 画面漂亮，但不知在讲什么 | 让首次观看者复述前后变化；区分没目标与目标未展示 | [01章](../methods/01-goals-research.md)01-01；[02章](../methods/02-structure.md)02-01/02-04 | [支架案例](../cases/02-product.md)：先选展示或教会操作 |
| 开头吸引人，结尾却失望 | 开头承诺了什么，结尾是否兑现；是否面向不同受众 | [01章](../methods/01-goals-research.md)01-03；[02章](../methods/02-structure.md)02-03 | 改承诺或补兑现，不先加反转 |
| 不紧张，只是让人困惑 | 观众是否知道风险、目标及等待的结果 | [02章](../methods/02-structure.md)02-02 | [伞案例](../cases/01-umbrella.md)：先查知情关系再延长停顿 |
| 反转像临时编的 | 揭示能否解释之前具体行动；是否自然限制了信息 | [02章](../methods/02-structure.md)反转/伏笔补充实践 | 回看线索和人物权限，不只在结尾加一句解释 |
| 对白听懂了，人物仍没变化 | 找到人物目标、策略和对方的实际反应 | [03章](../methods/03-performance.md)03-01/03-02；[08章](../methods/08-time-editing.md)ED01 | [对话D0/D1/D2](../cases/04-dialogue-attention.md)：比较看谁及何时换 |
| 纪录剪完更顺，却改变了事实 | 每句话能否回到原问题；画面是否冒充同步反应或证据 | [01章](../methods/01-goals-research.md)01-02；[03章](../methods/03-performance.md)03-04 | [纪录提纲](../cases/03-documentary.md)与MC06双索引；缺证据就标待核 |

## 空间、画面与运动

| 遇到的问题 | 先做的检查 | 可选技法与入口 | 练习或返修方向 |
|---|---|---|---|
| 人物左右关系突然反了 | 画俯视图，检查跨轴、视线和运动方向 | [05章](../methods/05-staging.md)ST02；[08章](../methods/08-time-editing.md)ED02 | 先补定向或连续跨轴，不把所有镜头机械水平翻转 |
| 镜头很近，关键动作仍看不清 | 检查遮挡、取景下缘、对焦和最终屏幕尺寸 | [06章](../methods/06-camera.md)CA01/CA02；[05章](../methods/05-staging.md)ST03 | 支架脱手或对话递接：扩大证据区域 |
| 运镜复杂却没有作用 | 起点与终点分别新增什么信息；主体与相机各怎样移动 | [06章](../methods/06-camera.md)CA04| 做固定版比较；相机参数不等于观看目的 |
| 风格参考很多，成片仍不统一 | 写跨镜规则：构图、运动、颜色、声音各允许怎样变化 | [04章](../methods/04-world-style.md)04-03/04-04 | 对照F02形式分析；不要只复制调色或导演姓名 |
| 调色后主体失去辨识度 | 对比关键物体颜色、亮度和背景竞争 | [07章](../methods/07-light-color.md)LC01/LC02/LC03 | 先修美术/光源或基础匹配，再做风格处理 |
| 动画轻飘或接触不可信 | 看重心、预备、速度间距和实际接触帧 | [11章](../methods/11-animation.md)T11-01/T11-02 | [机械臂关键帧](../demos/sound-priority.md)：先检查几何，再加音效 |

## 时间、声音与观看条件

| 遇到的问题 | 先做的检查 | 可选技法与入口 | 练习或返修方向 |
|---|---|---|---|
| 拖沓，但加快剪辑也没改善 | 哪些时段新增信息，哪些只是重复；必要反应是否已读完 | [08章](../methods/08-time-editing.md)ED01/ED04 | 先删重复行动或改场景任务，再改镜头时长 |
| 节奏太满，看完很累 | 同时要看、听、读多少件事；是否所有段落同样强 | [08章](../methods/08-time-editing.md)节奏变量；[10章](../methods/10-text-graphics.md)T10-01 | 错开字幕和关键动作，给反应与结果留时间 |
| 音效齐全却听不出重点 | 主导声是否与竞争声同频段/同时间；是否误降了总线 | [09章](../methods/09-sound.md)SO02/SO05 | [S0/S1媒体对照](../demos/sound-priority.md)：检查只改DETAIL的结果，尚待听审 |
| 换音乐后人物像变了一个人 | 音乐改变了情感立场，还是只是提高响度 | [09章](../methods/09-sound.md)SO03 | 同画面两版音乐或撤音乐；记录解释差异 |
| 画面接上了，声音仍像断了一下 | 查环境底声、句尾、声源位置与跨切时段 | [09章](../methods/09-sound.md)SO01/SO04 | 独立整理声轨边界，不能只拉长一句话 |
| 字幕存在却来不及读 | 按实际屏幕播放，检查阅读时间与动作竞争 | [10章](../methods/10-text-graphics.md)T10-01/T10-02/T10-03 | 减字、错峰或延长，不只缩小字号 |

## 执行与返修

| 遇到的问题 | 先做的检查 | 可选技法与入口 | 练习或返修方向 |
|---|---|---|---|
| AI每镜都漂亮，但拼不起来 | 逐镜列身份、道具、姿态、方向和入出状态 | [A1](../ai/A1-content-design.md)AI13-01/AI13-03 | 按[工作表](06-project-worksheets.md)管理参考职责；相同种子不保证连续 |
| 同一张脸或同一间房每镜都变 | 参考是否同源；下一镜是否改用了另一套图或重新文生 | [A3](../ai/A3-consistency-yield.md)；[备忘](../ai/higgsfield.md)只提供某厂商的训练限额 | 先批准静帧再派生。训练身份若不能导出，台账记平台内名称和批准帧 |
| 分镜帧和后来的视频对不上 | 镜头表是否先写了景别、运镜、用途和参考职责 | [05章](../methods/05-staging.md)；[A1](../ai/A1-content-design.md) | 先改静帧。一次能出的帧数不够就拆批，不在成片里补设计 |
| 口型像后贴，或环境声里冒出对白 | 分清同一次生成的声音和后期口型；对白、环境、音乐是否分轨 | [09章](../methods/09-sound.md)；[A4](../ai/A4-post-review.md) | 先定声部职责。厂商入口见[备忘](../ai/higgsfield.md)，不把“完美对齐”当成实测 |
| AI手部/产品反复失败 | 错误是否影响必要事实；是否有更可控制作方式 | [A1](../ai/A1-content-design.md)AI13-02| 缩减动作或用实拍/受控动画插入，不用快切掩盖证据缺失 |
| 拍了很多却缺可剪素材 | 必要信息有无覆盖，动作前后余量和物态能否接续 | [05章](../methods/05-staging.md)ST04；[12章](../methods/12-production.md)P12-02 | 按信息清单补镜，不盲目多拍近景 |
| 各方修改意见相互冲突 | 区分目标、事实、可读性和个人偏好 | [13章](../methods/13-review-delivery.md)R14-01/R14-02/R14-03 | 记录时间点与证据；回到主要受众目标，不以票数代替判断 |

## 三组常见选择

| 选择 | 更适合前者的条件 | 更适合后者的条件 | 共同检查 |
|---|---|---|---|
| 反应镜头 / 双人镜头 | 需要观察一个人怎样理解信息 | 需要看距离、姿态和双方互动 | 身份清楚，必要动作没有出框 |
| 长镜头 / 多镜覆盖 | 连续表演、空间过程本身有价值且能执行 | 信息尺度多变，需要调整注意或保留剪辑选择 | 每个节拍有作用；少切和多切都不是质量保证 |
| 保留声音细节 / 做声音减法 | 材质、过程或空间是观看重点 | 声部竞争掩盖关键行为或言语 | 因果声不能丢；不同音色不代表同等响度感 |

记录返修时写“观察事实→原因假设→最小改动→重新检查”。每次只修改可解释的一组变量；需要综合改动就列清清单，不伪称单变量实验。
