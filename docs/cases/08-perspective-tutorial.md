# 科普教程案例：为什么主体一样大，背景却不同

对应第06章CA02/CA04、第10章T10-01。附原创投影动画、机位图与参数。这个案例讲的是解释概念的组织方法，不是设备操作教程，也不代表真实镜头的全部表现。

## 简报与概念边界

目标：说明观察位置的变化与固定机位变焦的差别。受众已有“拉近画面”的直觉，但可能把移动摄影机和变焦混为一谈。解释采用“同样的前景尺度→观察背景差异→回到空间原因”，不先罗列焦距术语。

机制：移动相机改变它与前后景的距离比；固定机位变焦在理想投影中同比放大各平面的像。为排除前景大小这个显眼差异，两侧始终匹配前景尺度。证明范围限于本例几何条件，不推出任何固定的情绪含义。

## 空间与视觉规则

青色前景放Z=4，橙色背景放Z=8，物体大小各1；同一固定画面比例。左侧相机位置不变，只改f；右侧相机推进，只固定f。所有物体静止，不靠主体前后走动抵消摄影机运动。两侧用同样颜色、背景和构图中心，英语标签ZOOM/DOLLY区分操作。

配套[机位图与投影表](../demos/dolly-zoom.md)说明世界坐标及计算。字幕、旁白均不叠加到媒体内，避免在比较物体时同时阅读解释；说明放在播放前后的文档中。全片无音乐与音效，这是观看任务的选择，不是科普视频必须静音。

## 基础讲法与改进讲法

基础讲法只并排放两个不同大小的终点图并说“长焦压缩背景”。它遗漏了相机位置，难以区分哪项变化产生结果。这里只描述这种讲法的局限，没有制作或伪称持有它的实测失败视频。

本例改为可计算的共同空间、全程等大的前景、同时变化的对照及机位图。变化涉及解释顺序、视觉控制和证据呈现，是教学方案修订；不声称已经证明学习效果提高。

## 自动执行与验收

1. 把需要解释的关系转成变量：f、相机C、前景Z、背景Z，固定其余条件。
2. 用同一投影函数逐帧生成；给每种操作建立参数轨迹，不手调终点让图看起来“正确”。
3. 自动核对每帧前景宽度差小于1e-9像素（浮点计算值），终点背景比值不同；编码后核对帧数、时长。
4. 同时保存脚本、参数报告、起止图和机位图；可复现条件写进制作包。

## 常见错误与返修

| 错误 | 如何定位 | 如何修正 |
|---|---|---|
| 两侧主体大小不同却归因于透视 | 比较逐帧投影宽度 | 匹配前景尺度，再看背景关系 |
| 主体也移动了 | 查世界坐标轨迹 | 固定物体，分别控制相机与f |
| 把背景被遮后的可见部分当完整宽度 | 查遮挡和原投影边界 | 记录完整投影尺寸，图示说明遮挡 |
| 将理想几何当真实镜头全部表现 | 核对模型包含哪些因素 | 明示未模拟景深、畸变、呼吸等，不用此模型比较镜头品牌 |
| 光学讲解变成术语堆叠 | 检查每个图回答的具体问题 | 先展示共同条件和差异，再给变量解释 |

## 媒介适配与AI选择

本次选择程序化动画，因为投影与连续变量可精确控制。实拍迁移需要固定对象与机位记录，但不列为当前项目任务；三维动画可用虚拟相机复现同一坐标。
