# 对话观察对象：空间与剪辑图解

对应[对话案例：观众此刻应该观察谁](../cases/04-dialogue-attention.md)。这是一个交互图解：拖动时间轴，可以同时看到三个版本在同一时刻分别在看谁、谁在说话、道具在哪里。

[打开交互图解](dialogue-attention/interactive.html)

不方便运行网页时，可以直接看[俯视空间图](dialogue-attention/layout.svg)和[三版时间线](dialogue-attention/timeline.svg)。

## 先锁空间，再决定看谁

1. 在俯视图上标出甲在西、乙在东，甲乙连线是轴线。拍甲的机位在东南，拍乙的机位在西南，双人机位在正南。
2. 用画面方向核对：甲看画右、乙看画左；双人镜头里甲在左、乙在右。
3. 给每个镜头写“此刻要观察什么”：D0 看说话的方式；D1 先看乙如何判断，再看凭据进入关系，最后看甲如何接住信任。
4. 先固定公共动作和声音时点，再分配画面。举单、放单、推相机在三个版本里发生在同一时刻，切镜不能让道具回到原位。
5. 留出可见区域：拍甲的机位要能看到乙松手、甲接相机；双人机位要能看到单据从举起到落桌。
6. 想研究开场看谁，用 D2；想研究整场的注意力组织，用 D1。不能把 D1 的变化只归因于镜头更长。

## 三个容易混淆的数字

| 版本 | 编辑段数 | 观察对象变化次数 | 说明 |
|---|---|---|---|
| D0 | 5 | 4 | 按说话轮次切换 |
| D1 | 3 | 2 | 按判断过程切换 |
| D2 | 5 | 3 | 开头0—4秒改看乙，和4—8秒是同一机位的连续素材，4秒处没有可见切镜 |

## 空间出错时怎么改

- **反打后两人像朝同一方向看：** 检查是否有机位跨到了轴线北侧，回到南侧对应机位。不要用镜像画面来纠正，镜像会把持物的手和道具一起翻过来。
- **切镜后单据又回到手上：** 按同一时间选素材，检查原始动作是否同步。
- **接物镜头看不到乙松手：** 扩大取景，或三版统一加一个交接镜头，并重新计算时长。
- **想故意越轴表达关系转变：** 先设计一个连续移动或重新交代空间的镜头。越轴不是禁令，本练习固定同侧机位，只是为了减少对照变量。

## 局限

图解只表达空间和时间关系，不能体现口型、表情、表演节奏和声音。重建：

```sh
python3 scripts/build_dialogue_diagrams.py
node scripts/check_dialogue_diagrams.cjs
```
