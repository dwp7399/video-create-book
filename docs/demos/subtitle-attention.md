# 字幕与画面信息竞争：四版交互演示

对应[文字案例：让观众何时读、何时看动作](../cases/10-subtitle-attention.md)。拖动12秒时间轴，逐版比较文字的位置、分段和出现时机。

[打开交互演示](subtitle-attention/interactive.html)

画面动作：0—4秒方块在左侧等待，4—6秒移进右侧框，6秒框变绿，之后保持。两句说明文字：“把蓝色方块移到右侧框内。”“边框变绿后，表示已经到位。”

| 版本 | 位置 | 文字出现时段 | 与上一版的唯一差别 |
|---|---|---|---|
| P0 | 压在目标区域上 | 两句同时，0—8秒 | 有问题的原始版本 |
| P1 | 画面上方 | 两句同时，0—8秒 | 位置 |
| P2 | 画面上方 | 第一句0—4秒，第二句4—8秒 | 分段 |
| P3 | 画面上方 | 第一句0—4秒，第二句6—10秒 | 第二句延后到动作完成之后 |

P0 的文字底框完全挡住了目标框；P1—P3 不再遮挡。P3 让移动过程中没有文字，适合“先看后读”，但对需要边看边跟着做的观众可能提示过晚。四版没有绝对的优劣。

## 局限

演示用固定字号，实际效果会随字体、屏幕和观看距离变化，需要在自己的条件下试看。重建与检查：`node scripts/check_subtitle_attention.cjs`。
