# A4 后期、声音与验收

生成结束不是制作结束：要把候选拼成序列，处理声音，并用可重复的方法核对结果。本章的核对方法都经过实际使用。

## A4-01 用连接状态与合成把候选变为序列

**定义与机制。** 生成结束不是制作结束。后期把可用片段放入表达时序，修正可修缺陷，淘汰会改变事实的缺陷。匹配的重点是动作与信息接点，而非任意做叠化让不同画面“融起来”。适用于多镜片；单镜也需要声音、文字、颜色和输出检查。

**操作。**

1. 先按成片节拍摆放通过候选，登记源素材入出点；生成素材要有足够可用长度，不能为凑秒数冻结本应变化的动作。
2. 逐切点检查出入状态：A13-01→02并无递物；02→03伞仍在架；03→04林手未接触，反应不得展示已持伞。若状态矛盾，先换候选或补明确过渡，不靠短切隐藏。
3. 对齐角色尺寸、光向、色彩、视线和运动方向。翻转画面会交换持物手与门的位置，不能作为无成本修复。
4. 按公共声音表建立独立轨：环境0–16秒连续；门外层4–7秒；衣料与动作声按画面动作定位。生成音频有无均单独审核，不允许无依据的人声、商品描述或音乐抢改含义。
5. 做局部修复时标出范围：去除无关背景闪烁可用遮罩/合成；手与伞接触关系错误则通常要重做相应动作。文字、标志或产品精确细节可用受控资产合成，并检查遮挡和运动跟踪。
6. 先完成序列试看再精修。分别检查理解和缺陷，避免用调色或音乐遮住信息缺失。
7. 保存合成层、声音分轨、参考输入及选片记录，进入[评估与交付](../methods/13-review-delivery.md)。

**改写记录示例。** 若A13-03持续失败，可改为“林手停在柜台上，手指稍抬起又放下”，但这改变了接近伞的明确性；必须保留林看伞和后续望门的线索，重测是否仍能理解迟疑。另一方案是实拍原手部动作，保留原因果却增加道具与光色匹配成本。记录后选择，不把较易生成自动称为更好。

**错误→返修。** 四镜各自漂亮但人物位置跳变：回布局及候选选择；用叠化造成双重伞影：恢复硬切并修接点；口型被无关声音带动：换无说话素材或重新设计有依据的对白；每镜过度修复：回成本阈值，采用混合路线。

**检查与媒介适配。** 观众能复述等待者与林迟疑的关系吗？停顿是否支持期待？手、伞、空间、雨声是否连贯，输出全程有没有瞬间形变？合成是否增加新的维护成本？实拍同样需要选条和声音搭接；动画可回到曲线与布局修正；AI 需要先判断能否可靠局部返修，否则换镜/换路线。未实际生成前，只能验收设计完整性，不能给出“生成已成功”的结论。

## A4-02 声音：声画同生优先，后配只做补充

**定义与机制。** 后配声音时，声音时点来自计划，画面时点来自模型，两者天然错位；声画同生时，口型和撞击由同一次生成决定。

**实测。** 先生成无声画面，再用语音合成配上台词、按分镜秒数放好，台词文字经语音识别核对全部正确，但看起来声音和画面不匹配：人物张嘴和碰到东西的时刻，并不遵守分镜表的秒数。声画同生后，口型偏差约0.1秒，碰杯声滞后约0.2—0.3秒。

**操作。** 有对白、有接触声的镜头优先声画同生；后配只用于连续的环境床、跨镜的音乐，以及需要精确节拍的程序声音（如[11章D练习](../methods/11-animation.md)）。必须后配动作声时，先在画面里找出实际接触帧，再对齐声音，不能按分镜秒数直接放。

**剪辑时只做三件事。** 镜头都声画同生时，剪辑保留同期声：灰盒镜头的画外台词按时点铺入；无对白却编了人声的镜头换成同场环境声；整条序列统一到约 -23 LUFS。

## A4-03 自动核对：抽帧、ASR与能量曲线

AI成片数量大，逐条人工观看成本高；以下方法可以先筛掉明显问题，但不能替代人工观看与听审。

| 核对对象 | 方法 | 用法示例 |
|---|---|---|
| 画面内容 | 每条等距抽6帧拼图，按镜头契约逐项判断 | 批量审片，一张图看完一条候选 |
| 口型与接触时刻 | 在说话或接触时段每0.1—0.2秒抽一帧 | 声画同生对照 |
| 台词 | ASR转写，与剧本逐句比对 | 后配台词与声画同生成片 |
| 声音时点 | 逐0.1秒计算音频能量，找语音起止与撞击峰值 | 比较碰杯画面与声音峰值 |
| 版本差异 | 两版逐秒能量差 | 09章A0/A1只在6—9秒不同 |

**限制。** 抽帧会漏掉帧间的闪变；ASR只核对文字，不判断语气；能量曲线只能说明“此刻有声音”，不能说明是什么声音。

## 本章实践交付

交拼接表（每镜源入出点与连接状态）、声音方案（哪些同生、哪些后配及理由）、核对记录（抽帧、ASR、能量曲线结果）。没有人工观看与听审的，结论标“自动核对”。
